# 全球新聞脈動（Blogger 版，不需要 API Key）

Blogger 只負責顯示「新聞條列」與「摘要卡」，不連任何 API，版型裡沒有任何金鑰。新聞的翻譯與摘要，由每天 08:00、20:00 的排程在 Claude 裡完成。

## 使用流程
1. 首頁顯示新聞條列（分類、來源、時間、中文標題）。
2. 點某則新聞，先開出摘要卡（中文標題、原標題、重點摘要）。
3. 在摘要卡按「閱讀全文 ↗」，才會開啟外部連結。

## 貼進 Blogger 版型
佈景主題 → 備份/還原（先下載備份）→ 編輯 HTML。

| 檔案 | 貼到哪裡 |
|---|---|
| `blogger-1-css.txt` | 搜尋 `]]></b:skin>`，貼在它的正上方 |
| `blogger-2-html.txt` | 搜尋 `<div class='layout'>`，貼在它的正上方 |
| `blogger-4-data.txt` | 搜尋 `</body>`，貼在它的正上方（方案 B 才需要） |
| `blogger-3-js.txt` | 同樣貼在 `</body>` 正上方，放在 `blogger-4-data.txt` 之後 |

若你之前貼過 `news-worker` 資料夾的舊版（含 `.np-card`、`.np-grid`），請先把舊的三段刪掉，避免樣式重複。

## 新聞資料怎麼送進 Blogger：二選一

### 方案 A：自動更新（建議）
把 `news-data.json` 放到一個公開、允許跨網站讀取的位置，例如 GitHub Pages，然後在 `blogger-3-js.txt` 最上面的
`var NEWS_URL = '';` 填入該檔網址。頁面每次載入都會讀最新內容。這個方案不需要 `blogger-4-data.txt`。

### 方案 B：手動貼資料（不用任何主機）
`NEWS_URL` 留空，把 `blogger-4-data.txt` 貼進版型。每次更新時，把版型裡 `window.NEWS_DATA=` 那一段換成新的內容。缺點是每天要手動貼。
